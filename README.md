# Saku — 4-in-1 Offline-First Micro-Utility PWA

## Menjalankan Proyek
```bash
npm install
npm run dev
```

## Build Production (PWA + Workbox Offline)
```bash
npm run build
npm run preview
```

## Fitur & Shortcut Android
- `/?tab=keluar` — **Aman Keluar**: Checklist 5 detik sebelum berangkat dengan reset otomatis setiap ganti tanggal lokal (`YYYY-MM-DD`).
- `/?tab=napas` — **The Breathing Door**: Jeda napas 8 detik anti-doomscroll, scratchpad otomatis, dan penghitung harian *Reflek Tertahan*.
- `/?tab=terakhir` — **Kapan Terakhir**: Pelacak rutinitas dengan tombol reset 1-ketuk dan toast *Undo* 4 detik.
- `/?tab=simpan` — **Parkir & Simpan**: Spot parkir aktif dengan kompresi foto Canvas (`max-width: 800px`, JPEG 0.7) ke IndexedDB Blob + pencarian lokasi barang.
